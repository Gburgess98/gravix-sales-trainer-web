Product rule to keep front of mind: **Gravix does not own the call.**
Gravix listens to the call, coaches the rep, scores the session, and trains
the team.

## 4. Objection handling during the demo

- **"Does this replace the manager?"** — No, it gives the manager better
  focus. Every action in the product is a manager decision.
- **"Does it record calls?"** — Gravix reviews uploaded/synced recordings;
  it does not need to own the phone system.
- **"Can reps use it themselves?"** — Yes. Manager workflow first, rep
  workspace next.
- **"Is the AI auto-changing coaching rules?"** — No. Manager approval
  stays in control; AI only proposes candidates.
- **"Is this live coaching?"** — Whisperer support is in place; voice/audio
  advanced work is paused until demo value is proven.
